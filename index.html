Adding a book

Run the splitter on a PDF. It cuts the book into small files and adds each one to library/map.json:

python tools/build_library.py "Book.pdf" --title "Book title" --id book-id --summarize gemini --key YOUR_KEY

Then press Reload library. See README.md for page offsets and manual ranges.
